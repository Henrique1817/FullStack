LAB 7 — Servidor estático

O servidor Node + Express está em servidor/servidor.js (porta 80, pasta public/ estática, escuta em 0.0.0.0 para acesso por IP na rede).

  • Raiz do servidor (/) — redireciona a projects.html (LAB 8)
  • /Home.html — portal (alias do enunciado)
  • /Project.html — laboratórios (alias)

No Windows, use ipconfig para ver o IPv4 e abra no outro PC: http://192.168.x.x/Home.html (ajuste o IP).
